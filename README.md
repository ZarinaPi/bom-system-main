# Система ведения спецификаций изделий (BOM)

Проект для автоматизации процессов ведения спецификаций изделий, управления изменениями и расчёта сводных норм расхода.

## Стек
- Python 3
- Flask
- Flask-SQLAlchemy
- SQLite

## Возможности
- Ведение справочника изделий (материалы, детали, сборки, комплексы)
- Формирование иерархических спецификаций
- Расчёт сводных норм расхода на всю глубину вложенности
- Управление изменениями и создание модификаций на основе базовых изделий
- История изменений

## Запуск

Из корня проекта, Python 3.9 или новее:

```bash
python -m pip install -r requirements.txt
python -m bom.app
```

API BOM и маршрутной технологии доступен на `http://127.0.0.1:5001`.
Путь к базе SQLite — `bom/instance/bom_database.db`.

### Данные маршрутной технологии

Для пустой рабочей копии:

```bash
python -m bom.seed_technology --demo
```

Команда воссоздаёт фрагмент спецификации «Автомобиль Стандарт» (СБ-001)
из отчёта № 5 и добавляет демонстрационный маршрут 010 → 020.
Время операций, ставка и инструмент заданы для учебного примера.
Цены и нормы расхода взяты из отчёта. Для омывающей жидкости и топлива
в учебной базе используются литры.

Для работы с базой задания № 5 поместите её копию по указанному пути
и запустите `python -m bom.seed_technology` без `--demo`.
В состав СБ-001 должны входить Д-001, Д-002, Д-003, М-001 и М-003.
Команда использует фактические нормы и единицы измерения из этой базы.
Если у СБ-001 уже есть технологические позиции, команда пропускает изделие.

Чтобы узнать идентификатор СБ-001, вызовите `GET /api/bom/products`.
Для расчёта на два автомобиля вызовите `GET /api/tm/product/<id>/cost?quantity=2`.
В демонстрационной базе ожидается 27 600 за материальные ресурсы,
1 665 за труд и 29 265 суммарно.

## API
- `GET /api/bom/products` — список изделий
- `GET /api/bom/product/<id>/tree` — дерево состава (FIND_BOM)
- `GET /api/bom/product/<id>/calculate` — сводные нормы (CALC_BOM)
- `POST /api/bom/product/<id>/modification` — создание модификации
- `POST /api/bom/product/<id>/changes` — регистрация изменения
